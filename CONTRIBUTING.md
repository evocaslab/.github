# Contributing

Thank you for helping. Each repo has its own `CONTRIBUTING.md`; read that one first. If a repo has none, these defaults
apply:

- Open an issue before a large change, so we agree on the direction.
- Keep a change small and focused, with a test for new behaviour.
- Run the repo's checks before you open a pull request (`just` lists the recipes where the repo has a justfile).
- Do not include secrets, personal data or third-party content in an issue, a commit or a pull request.
