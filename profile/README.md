# EvoCAS Lab

**Analysis and synthesis, as code.**

EvoCAS Lab (Evolving Comprehensive Analysis and Synthesis Lab) takes systems apart, measures them and puts them back
together as small tools and apps: checks without a model, documents from specs, brands from a file.

- Website: [evocaslab.com](https://evocaslab.com)
- Tool docs: [docs.evocaslab.com](https://docs.evocaslab.com/)

## Public tools 🧰

<!-- projects:begin -->
- [atlas](https://github.com/evocaslab/atlas): architecture, checked against the code. A YAML model of elements and
  relations, validated against the code and exported to diagrams, for AI-assisted development.
- [dossier](https://github.com/evocaslab/dossier): check a repo's dossier (purpose, reasoning, design, contract,
  trust, help, agent files) by repo kind, with no LLM; CI-ready.
<!-- projects:end -->

Each tool's guide is on [docs.evocaslab.com](https://docs.evocaslab.com/).
