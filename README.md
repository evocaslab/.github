# .github

The organisation's root repo. It holds:

- `profile/README.md`: the text on the organisation page at github.com/evocaslab. GitHub shows it only while this repo
  is **public**.
- Later, default community health files (`SECURITY.md`, `CONTRIBUTING.md`, issue and pull request templates) that every
  repo without its own copy inherits, and starter workflows.

This repo must stay public: making it private removes the profile page and the defaults. Defaults held now:
`SECURITY.md` and `CONTRIBUTING.md`; a code of conduct and `workflow-templates/` come when needed.

Keep it short and free of anything private: no repo names that are not public yet, no names of people or clients.
