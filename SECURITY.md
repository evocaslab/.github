# Security policy

Report a vulnerability privately. Never put the details in a public issue.

1. If the repository's **Security** tab shows **Report a vulnerability**, use it (GitHub private vulnerability
   reporting). It is switched on for our public repositories.
2. If the button is not there (GitHub offers it on public repositories only), email **security@evocaslab.com**.
   If you cannot email, open an issue titled "Security contact request" with no details; the maintainer replies
   with a private way to send them. If you are a collaborator on a private repository, contact the maintainer
   directly.

Include what you found, how to reproduce it and the version. We acknowledge a report within a few working days and
tell you when it is fixed. A repo with its own `SECURITY.md` follows that file instead.
